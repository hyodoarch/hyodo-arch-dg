# {{ title }}

| 項目 | 内容 |
| --- | --- |
| Q | 相談したいのですが、どうすればいいですか？ |
| A | まずはお問合せフォーム・電話にてお気軽にご連絡下さい。一般的なご質問には、すぐにお返事致します。更に具体的なご相談の場合は、資料をご持参の上事務所にお越し頂き、お話を伺います。 |

| 項目 | 内容 |
| --- | --- |
| Q | 相談の際に必要な資料は何ですか？ |
| A | あると良い資料は、次のようなものです。 <br> ・敷地の図面や様子がわかる写真、容積率、建ぺい率がわかる資料<br> ・リノベーション（改装）や増築の場合は、現状の平面図<br> ・予算や建物の要望などをまとめたもの（箇条書きで結構です） |

| 項目 | 内容 |
| --- | --- |
| Q | とりあえず事前プレゼンテーションを依頼したいのですが、どうすればいいですか？ |
| A | どのような住まい方、使い方をお考えなのか？建物にはどのようなご要望をお持ちなのか？普段どのような生活をなさっているのか？などをヒアリングをさせて頂きます。資料をご持参の上事務所にお越しください。必要な資料は、相談の際に必要な資料と同じで、次のものです。 <br> ・敷地の図面や様子がわかる写真、容積率、建ぺい率がわかる資料<br> ・リノベーション（改装）や増築の場合は、現状の平面図<br> ・予算や建物の要望などをまとめたもの（箇条書きで結構です） |

| 項目 | 内容 |
| --- | --- |
| Q | 予算が少ないのですが？ローコスト住宅は依頼できますか？ |
| A | はい、設計できます。ご予算の相談にも応じます。ローコストでも快適で、建売住宅とは違う独自の雰囲気を持ちながらも美しく、安っぽくない家を建てることは難しいことではありませんし、設計者の立場としてもローコストは面白い仕事です。お客様とよく話し合い、現実の問題に向き合い、よく考えてアイデアを重ね、一緒に良い家を造りたいと思っています。 |

| 項目 | 内容 |
| --- | --- |
| Q | デザイン・スタイルの希望があるのですが、たとえばバリ・リゾート風の住宅を依頼することはできますか？ |
| A | はい、できます。当方は、決まったスタイルを押し付ける設計事務所はなく、クライアントの意向に沿った建物を実現するために、ヒアリングを丁寧に行い、リサーチし、検討を重ねその状況に相応しい提案をするタイプの設計事務所です。 |

| 項目 | 内容 |
| --- | --- |
| Q | 設計事務所へ依頼してやってくれることと、ハウスメーカーに依頼してやってくれることの違いがイマイチわかりません。簡単に説明してもらえますか？ |
| A | 設計事務所は、設計・監理というソフトを提供するサービス業のようなもので、建設というハードを作ることはしません。設計事務所の役割は、お客様の求める建物を設計し、建設する工事会社の選定や工事金額に関してアドバイスを行い、工事会社が設計図どおり施工する（できる）ように監理することです。<br> それに対してハウスメーカーは、設計、監理、施工の全てを一社で行います。 |

| 項目 | 内容 |
| --- | --- |
| Q | 設計の流れを読みましたが、設計事務所へ依頼するのは面倒な印象を受けました。それでも何かメリットはあるのですか？ |
| A | 確かに、ハウスメーカーへ依頼するより、色々とやることが増えるので面倒に感じる方もいらっしゃると思います。設計事務所とハウスメーカーのどちらに依頼するか迷われた上で、最終的に設計事務所に依頼された方で多いと感じるのは、ハウスメーカーのプランニングに満足されなかったか、機能的要望が満たせなかった方です。設計事務所による設計は、お客様が主体的に選択・決定できる幅が広く、柔軟であることです。 |

| 項目 | 内容 |
| --- | --- |
| Q | 設計を依頼してから完成までどのくらいの期間がかかりますか？ |
| A | プレイン・ハットの場合、6～9ヶ月、新築住宅の場合で12～18ヶ月くらいです。リノベーションやテナントに入居する店舗の場合は、3～8ヶ月くらいです。建物の規模や内容にも寄りますので、詳しくはご相談ください。 |

| Q | 遠方からの依頼は可能ですか？ |
| A | はい、お引き受けします。これまでに西は長野県上田市、東は千葉県香取市で設計・監理した実績があります。遠方の目安は、公共交通機関の片道料金が1500円を超える場合です。遠方の場合、交通費を別途いただくことになりますが、最初にお見積りいたしますので、お問合せください。 |

| 項目 | 内容 |
| --- | --- |
| Q | 設計料は、いつ支払えば良いですか？ |
| A | 基本的に、契約時に設計料総額の 10%、基本設計完了時に 30%、実施設計完了時に 30%、竣工時に 30% とさせて頂いております。 |

| 項目 | 内容 |
| --- | --- |
| Q | 設計・監理契約を解約したい場合は、どうなりますか？ |
| A | 契約後も、お客様の意向でいつでも解約することができます。設計料の清算は、解約時までの業務をお互い確認し、話し合いの上、決定します。 |
