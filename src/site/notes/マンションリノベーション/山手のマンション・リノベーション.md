# {{ title }}
{% noteTags %}

神奈川県横浜市に計画した築浅の中古マンションのリノベーションです。

横浜のこの環境を気に入ったご夫婦が購入した築浅の中古マンションを全面リノベーションしました。2005年竣工の比較的新しい物件だったので既存部位、既存のユニット・バス、システム・キッチン、便器、電機設備の再利用だげでなく、既存の床、壁の解体を限定することにより、スケルトン・リノベーションの工事費の約 50% で実現できました。

```image-grid-captions
columns: 2
gap: 8

![[images/apt-reno/yamate/yamate_IGP0556.jpg|## マンションに土間を設ける

玄関にも使える多用途の土間です。元のプランでは、玄関ドアを開けるといきなり壁でした。それが息苦しかったので、既存の壁を壊して土間スペースにしました。自転車が置けたりするインナーバルコニーのようなちょっと贅沢な空間です。左の和障子で隣の主寝室と仕切ることにより、マンションの欠点である共用廊下と住戸内の居室の近すぎる距離を確保し、プライバシーを高めることにも役立っています。]]
![[images/apt-reno/yamate/yamate_IGP0554.jpg|## 廊下も快適な空間にする

マンションの廊下は、ただ歩かされるためだけの空間であることが多いので、寝室の境をガラスの建具（右側）にすることによって視線が通るようにし、木製建具（左側）によって隣室の空間を感じられるようにして、心理的な狭さや暗さを和らげています。

廊下も快適な空間にしました。]]
```

![[images/apt-reno/yamate/yamate_IGP0526a.jpg|++リビングの木製ブラインド]]

## 木製ブラインドでアルミサッシを隠す

廊下からリビングに入りバルコニーの窓を見たところです。窓には木製ブラインドを下げ、網戸も木製にしています。それだけでマンションのインテリアがナチュラルな印象になります。

![[images/apt-reno/yamate/yamate_IGP0605a.jpg|++リビングのモルタル壁]]

## リビングの様子

クライアントがリビングを使っていらっしゃる様子です。正面のグレーの壁は、改装前のビニルクロスを剥がした際に現れたモルタル壁で、程よくきれいでラフなので塗装せず見せてみることにしました。

![[images/apt-reno/yamate/yamate_IGP0500.jpg|++リビングから廊下を見る]]

## 回遊同線を作る

リビングから廊下を見たところです。右側の通路は廊下で、左側は書斎スペースです。書斎スペースから主寝室へ行く動線を新たに設けることによって回遊性が生まれました。

```image-grid-captions
columns: 2

![[images/apt-reno/yamate/yamate_IGP0546.jpg|## 書斎をリビングの一角に設ける

書斎をリビングの一角に設け、且つ寝室にアクセスできる位置にしています。リビングのはずれの低天井部分にある落ち着いたスペースです。カウンターは、機能別に奥行きを変化させています。奥の扉付きの部分は食器棚（奥行 300mm）、中間は AVラック（奥行 400mm）、手前は書斎スペース（奥行 500mm）です。]]
![[images/apt-reno/yamate/yamate_IGP0614.jpg|## 主寝室を広く見せる

右側のガラス建具の向こうは廊下です。棚はベッドのヘッドボードになります。左側の和障子は、土間を仕切り外部共用廊下からのプライバシーを確保しています。建具に囲われ広く感じられます。

主寝室が広く見えるようにしています。]]
```

## DIYで床を塗装

クライアントと兵藤事務所で床をオスモフロアカラーで塗装しました。それにより塗装工事を節約すると同時に、床のワックス塗布をご経験いただくことによりメンテナンスも DIY で出来るようになります。フローリング材は体育館などで使うナラ・パーケット材の無塗装品です。リビングには床暖房が入っていたのですが、効率を下げず、床解体も行わないで済む木質系床材をいろいろ検討した結果、ナラ・パーケット材に決定しました。
