# {{ title }}
{% noteTags %}

埼玉県越谷市に計画した1階と2階をロフト階でつないだ店舗 兼 2世帯住宅です。

1階道路側に店舗入口、庭側に両親住居入口、外階段を上って2階に夫婦住居入口があります。上の写真の左側が店舗です。店舗の上はロフトになっており、ロフトを介して上下階が内部でつながっています。各世帯は、玄関・キッチン・浴室・洗面・トイレが独立しています。

## 2階 土間とテラス

子世帯は、2階なので土に接した庭が設けられないので、代わりに広い土間とテラスを設けています。また木製の引込み戸を開放することにより、外部とつながります。

左の写真は、リビングから土間とテラスを見たところです。土間を介することで、外部との適度な距離が生まれます。右の写真は、土間からテラスを見たところです。土間を軒下のような半外部空間です。

![[images/house/house_in_koshigaya/koshigaya-03_IGP0057.jpg|++2階 リビング・ダイニング]]

## 2階 リビング・ダイニング

屋根の梁などの構造材を室内側に見せ、天井を少しラフな表現にしました。それにより、大きな片流れの屋根がどの部屋でも感じられ、2階全体に一体感があります。

![[images/house/house_in_koshigaya/koshigaya-05_IGP0099.jpg|++2階 寝室]]

## 2階 寝室

入口が2箇所ある細長い部屋なので、将来ふたつの部屋に仕切ることも可能です。3畳のウォークインクローゼットもあります。

## 1階 リビングと土間

リビングから土間を介して庭につながります。飼っていらっしゃる犬は、寒いときは土間に入れてあげるようです。

## 1階 和室の続き間

ご両親の寝室に使われる和室はリビングに面しています。欄間に透明ガラスを入れ、リビングと天井を連続させ、広く感じるようにしました。ふすま紙は、無地の銀河鳥の子和紙です。
