# {{ title }}
{% noteTags %}

さいたま市岩槻区に計画した5戸の長屋です。
ワンルームタイプ（8畳）が３戸、1LDK タイプ（10畳＋5畳）が２戸のゆとりのある賃貸です。

予算が限られる中、配置とプランにこだわり、開口部を絞りながらレイアウトし、色彩計画にも凝ってみました。

![images/house/iwatsuki/iwatsuki-03_DSC04051.jpg\|++玄関ホール\|left\|317](/img/user/images/house/iwatsuki/iwatsuki-03_DSC04051.jpg)

## ファサード（上）

玄関の庇を境に色を分けて変化を付けました。玄関ドアが通りに面しているので目隠しルーバーを設置しています。

## 玄関ホール（左）

廊下から玄関ホールをドアを開けた状態で目隠しルーバーが見えます。左側に靴箱とクローゼット、右側に水回りのドアがあります。

![images/house/iwatsuki/iwatsuki-04_DSC04059.jpg\|++ワンルームタイプ](/img/user/images/house/iwatsuki/iwatsuki-04_DSC04059.jpg)

## ワンルームタイプ

天井高のサッシを入れ、壁との比率を少し操作することによって、部屋をスッキリと見せ、アクセント・クロスで変化を付けています。

![images/house/iwatsuki/iwatsuki-02_DSC04060.jpg\|++ワンルームタイプのミニ・キッチン](/img/user/images/house/iwatsuki/iwatsuki-02_DSC04060.jpg)

## ワンルームタイプのミニ・キッチン

黒いキッチンに木目の不燃クロスにすることによって、キレイにまとめました。

![images/house/iwatsuki/iwatsuki-05_DSC04103.jpg\|++1LDKタイプのLDK](/img/user/images/house/iwatsuki/iwatsuki-05_DSC04103.jpg)

## 1LDKタイプのLDK（上）

## 1LDKタイプの寝室（左）と浴室（右）

寝室には、大きなクローゼットを設け、グレーのクロスをアクセントにしました。浴室はワンルームタイプ少し広めの 1216 サイズでバス乾燥機を設置しています。
