# {{ title }}
{% noteTags %}

埼玉県川口市に計画した、6人家族のための二世帯住宅です。

クライアントはもともとこの敷地に2棟の住宅をお持ちで別居されていましたが、ご両親が高齢のため二世帯住宅に建て替えて同居することをお考えでした。1階にLDK、水廻り、主寝室を配し、ディテールにはバリアフリーを意識しました。

## 玄関ポーチ

ベンチの下がポストになっていて、毎朝朝刊新聞を読みながらコーヒーが飲めるよう玄関ポーチにベンチを設けました。
