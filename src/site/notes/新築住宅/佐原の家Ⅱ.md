# {{ title }}
{% noteTags %}

千葉県香取市佐原に計画した、夫婦+子ども2人のための家です。

敷地は小野川沿いの香取市佐原の風致地区区域に近いため、周辺との景観の調和が必要でした。クライアントの要望もあり佐原という町にふさわしい景観を形成しながら、素材とインテリアをご提案しました。
