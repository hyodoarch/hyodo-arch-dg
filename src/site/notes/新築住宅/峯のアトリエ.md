# {{ title }}
{% noteTags %}

革小物職人さんのためのアトリエと住まいです。

クライアントは革小物の製造と販売を行っているご家族でした。もともと住んでいた家が手狭になったため、近所の土地を購入してアトリエ兼住まいを新築しました。

クライアントは革小物職人さんで自宅で作業できるアトリエと在庫管理ができるオフィススペースが必要でした。そこで建物中央に玄関、階段、廊下を配置してアトリエと住居部分を左右に分けました。アトリエには様々な種類のミシンと皮革を加工する重機を置く予定です。
