# {{ title }}
{% noteTags %}

革小物職人のためのアトリエ兼住まいです。

クライアントは革小物の製作・販売を営むご家族でした。従来の住まいが手狭になったことから、近隣の土地を購入し、アトリエを併設した新たな住まいを計画しました。

![images/house/atelier-m/atelier-m-03_g_IGP4335.jpg\|++道路側外観](/img/user/images/house/atelier-m/atelier-m-03_g_IGP4335.jpg)

## ファサード
屋根材は遮熱性と反射率の高いカラーガルバリウム鋼板です。外壁はジョリパットのゆず肌仕上げです。クライアントには多くのサンプルから選んで頂きました。桧材で製作した木製建具と目隠し格子を設け、外観のアクセントとしました。玄関ポーチの壁にはポストとインターホンを組み込み、機能と意匠を一体的に計画しています。

## 歩道から距離を取り奥行を持たせた玄関ポーチ
玄関ポーチは外壁を一部凹ませ、その奥に配置することで歩道からの距離を確保しました。雨の日でも玄関の出入りの際に濡れにくく、傘を広げたりできる十分な広さを備えています。日々の何気ない動作を受け止める、ゆとりある玄関空間となりました。
玄関ドアとドア枠は桧材で製作し、片側に設けたスリット窓から柔らかな自然光を取り込んでいます。

クライアントは革小物職人さんで自宅で作業できるアトリエと在庫管理ができるオフィススペースが必要でした。そこで建物中央に玄関、階段、廊下を配置してアトリエと住居部分を左右に分けました。アトリエには様々な種類のミシンと皮革を加工する重機を置く予定です。
