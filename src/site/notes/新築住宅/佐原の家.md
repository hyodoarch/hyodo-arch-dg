# {{ title }}
{% noteTags %}

シンプルな矩形のファサード。

素っ気なくならないように、屋根付きポーチを設けました。

壁はガルバリウム鋼板防火サイディング。

開口部はアルミサッシ。

建物手前の土間コンクリートは車一台分のスペースで、4台駐車可（内3台分は家族用）。

![images/house/house_in_sawara/sawara_IGP2438.jpg\|++アプローチとポーチ\|right\|317](/img/user/images/house/house_in_sawara/sawara_IGP2438.jpg)

3世代 4人家族のための住宅です。現在はお子さんがひとり増え、5人家族です。
		敷地は街から少し離れた住宅用分譲地にあり、周辺は田んぼが点在し、南西側のJR成田線の向こうには丘が見え眺めの良く、北側には利根川へ流れ込む水路の土手が見えます。

クライアントのご要望は、①シンプルな外観、②広い２階リビング、③４つの個室、④４台分の駐車スペース、でした。そこで敷地北側の私道に駐車スペースを取り、シンプルな直方体のボリュームを南側の農道に寄せ、両隣の建物から均等にスペースを空ける配置としました。

### アプローチとポーチ

屋根付きポーチはスチールで製作し、目隠しにポリカーボネイト板を取り付けました。アプローチの踏み石はプレキャストコンクリート平板です。

![images/house/house_in_sawara/sawara_IGP1830.jpg\|++階段・ホール](/img/user/images/house/house_in_sawara/sawara_IGP1830.jpg)

![images/house/house_in_sawara/sawara_IGP2427.jpg\|++階段の上り口](/img/user/images/house/house_in_sawara/sawara_IGP2427.jpg)

階段の上り口

2階のブリッジよりスリット状の光が降りそそぎます。

![images/house/house_in_sawara/sawara_IGP1799.jpg\|++階段全景](/img/user/images/house/house_in_sawara/sawara_IGP1799.jpg)

階段全景

階段は建物の中央に位置するため、そのままだと暗くなります。

安易に天窓を設置すれば夏は暑くなってしまいます。

そこでリビング側の壁にランマを設け光が階段へ落ちるようにしました。

## 階段・ホール

2階リビングのため、2階への上り下りが楽なように階段の段数を減らし、階段ですれ違うことができるように幅を広く取りました。中央の小窓は、個室とホールの通風窓で、家族間のコミュニケーション・ツールにもなっています。

![images/house/house_in_sawara/sawara_IGP2420.jpg\|++リビング・ダイニング](/img/user/images/house/house_in_sawara/sawara_IGP2420.jpg)

## リビング・ダイニング

広さは 16畳ですが、開口部を1.8mと低めにし天井高を2.6mと少し高めにすることによって、寸法比を大きくし、視覚的には実際以上に広く感じる空間となっています。

### リビングからの風景

目の前に稲のグリーンが広がります。窓外の格子はバルコニーの手摺。右の白い台はベンチです。
