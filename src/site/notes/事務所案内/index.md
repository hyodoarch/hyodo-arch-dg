# {{ title }}

![兵藤善紀建築設計事務所](/img/user/images/common/profile-IMGP4364.jpg)

当設計事務所は、住宅、リノベーション、店舗・オフィスデザインを業務の中心として、埼玉県川口市を拠点に活動する一級建築士事務所です。事務所はパートナーの経営する作家もののうつわやテキスタイル等を扱う雑貨の店 [『くらしの道具』](http://www.kurashinodogu.jp/) とシェアしています。どうぞお気軽にお立ち寄りください。
