# {{ title }}
{% noteTags %}

埼玉県川口市の企業からのご依頼で、倉庫を事務所へリノベーションしました。

倉庫のラフなイメージを生かしながら空間を構成し、断熱、空調効率、照明計画、通信設備、メンテナンス性など、現代の事務所に求められる機能・快適性を追求しました。


![[images/shop-office/npro/Npro_IGP3236.jpg|++事務所スペース]]

## 事務所スペース

1階のこのエリアは元々事務所として使われていました。改装後も面積は変わらないので、天井を取り払い広がりのある空間にしました。天井を取り払ったことにより、断熱工事範囲を少なくし、空調・電気設備の施工性を上げ、天井の荷重を2階床仕上げに置き換えることができました。改装前の床は土間コンでしたので、断熱材を敷き詰めシステムフロアで床レベルを上げ、電源、情報インフラを床下に敷設しました。情報ケーブル敷設はさや管を使用し、メンテナンス性を考慮しています。

![[images/shop-office/npro/Npro_IGP3132.jpg|++カフェテリア]]

## カフェテリア

2階は社員の福利厚生を主目的としたスペースです。カフェテリアで社員の皆さんはランチを食べたり、会社でのパーティーなどに使用しています。左側の青い壁は、カラーガルバリウム鋼板の外壁材で、会社のコーポレートカラーに合わせています。

![[images/shop-office/npro/Npro_IGP3160.jpg|++アイランド・キッチン]]

## アイランド・キッチン

カフェテリアの一角にアイランド・キッチンを設けました。腰壁はシルバーのガルバリウム鋼板の外壁材です。左の廊下は、ロッカー室、洗面室、トイレへつながっています。

![[images/shop-office/npro/Npro_IGP3145.jpg|++会議室]]

## 会議室

カフェテリアと引戸で仕切れるようにしたエリアは、会議室としても使えるようになっています。

## 改装前の様子

倉庫なので、既存事務所は断熱されていませんでした。非常に寒かったそうです。
