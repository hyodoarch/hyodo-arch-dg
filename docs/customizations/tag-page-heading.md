# タグ一覧の見出し

確認日：2026-11-19。`/tags/<タグ名>/` の先頭を、角丸枠で囲むh2「#平屋」とh2「タグの事例です。」の横並びにする。

## 対象と復元

- repo相対 `src/site/tags/tag.njk`：独自タグ一覧テンプレート。h2にエスケープしたタグ名と#を表示し、説明文もh2にする（既存h2と同じ18px・太字）。#はHTML文字参照 `&#35;` で出力し、既存taggifyによる自己リンク化と内側のタグ装飾を防ぐ。
- repo相対 `src/site/styles/user/hyodo-arch.scss`：ユーザー拡張。`.tag-page-heading` 内だけにflex・中央揃え・8px/12pxの行間/列間・下24pxを指定。タグ枠のh2は本文と同じ16px、1pxグレー枠・6px角丸・薄いグレー背景・上下4px左右10px。後続一覧の上27pxはこの位置だけ0にする。674px以下はmain直下の本文見出し・段落と同じ `padding-inline: 9px` をラッパーにも適用する。
- repo相対 `docs/customizations/README.md` と本記録：独自資料。

独自追加・ユーザー拡張なので通常の更新では残るが保証ではない。テンプレート・フォルダー全体の置換やCSS読込仕様の変更で消失すると、枠や横並び・余白が失われる。標準ファイルの丸ごと置換で復元せず、この記録を基に対象部分を再統合する。復元元は本記録と対象ファイルを保存したGitコミット。`git log -- src/site/tags/tag.njk docs/customizations/tag-page-heading.md` で対応版を確認する。

## 確認方法

Node22で `npm test` と `npm run build`。生成したタグ一覧をPC・390px・320pxで開き、h2の#と実タグ名、説明h2の文言・18px太字、横並びと中央揃え、一覧まで24px、PCでは画像との左揃え、674px以下では本文と同じ左右9pxの余白を確認する。長いタグは説明文を次行へ送り、枠内の文字を分割しない。画面幅より長いタグ自体は枠内の横スクロールで全文を読めるようにする。

本文に埋め込むタグ別作品一覧はこの見出しの対象外。公開入力のノートやタグ名は変更しない。

2026-11-19。説明をpからh2へ変更し、通常のh2指定（18px・太字）を利用する。スマホで左端に寄る原因は、本文の左右9pxのpaddingがmain直下の見出し・段落だけを対象とし、divのタグ見出しラッパーが含まれていなかったこと。同じセレクター群へ `.tag-page-heading` を追加し、674px以下で左右9pxを適用した。作品画像の余白指定は変更しない。
