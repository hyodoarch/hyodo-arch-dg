# タグ一覧の見出し

確認日：2026-11-19。`/tags/<タグ名>/` の先頭を、角丸枠で囲むh2「#平屋」とp「タグの事例です。」の横並びにする。

## 対象と復元

- repo相対 `src/site/tags/tag.njk`：独自タグ一覧テンプレート。h2にエスケープしたタグ名と#を表示し、pに説明文を置く。#はHTML文字参照 `&#35;` で出力し、既存taggifyによる自己リンク化と内側のタグ装飾を防ぐ。
- repo相対 `src/site/styles/user/hyodo-arch.scss`：ユーザー拡張。`.tag-page-heading` 内だけにflex・中央揃え・8px/12pxの行間/列間・下24pxを指定。h2は本文と同じ16px、1pxグレー枠・6px角丸・薄いグレー背景・上下4px左右10px。後続一覧の上27pxはこの位置だけ0にする。
- repo相対 `docs/customizations/README.md` と本記録：独自資料。

独自追加・ユーザー拡張なので通常の更新では残るが保証ではない。テンプレート・フォルダー全体の置換やCSS読込仕様の変更で消失すると、枠や横並び・余白が失われる。標準ファイルの丸ごと置換で復元せず、この記録を基に対象部分を再統合する。復元元は本記録と対象ファイルを保存したGitコミット。`git log -- src/site/tags/tag.njk docs/customizations/tag-page-heading.md` で対応版を確認する。

## 確認方法

Node22で `npm test` と `npm run build`。生成したタグ一覧をPC・390px・320pxで開き、h2の#と実タグ名、pの文言、横並びと中央揃え、一覧まで24px、画像との左揃えを確認する。長いタグは説明文を次行へ送り、枠内の文字を分割しない。画面幅より長いタグ自体は枠内の横スクロールで全文を読めるようにする。

本文に埋め込むタグ別作品一覧はこの見出しの対象外。公開入力のノートやタグ名は変更しない。

2026-11-19、Node22.23.3で既存643テストと公開用build成功。ローカル生成した全70タグを1440px・390px・320pxの計210条件でEdge検証し、#付きh2、リンク装飾なし、文言、16px文字、枠、左揃え、一覧まで24px、横はみ出しなしを確認。長いタグ名を一時的に画面へ設定し、狭幅で説明文が次行に移りタグ内改行がないことも確認。平屋のPC・390px画像を目視確認した。
