# グラフビューのタグ表示

同じタグを持つ公開ノートを一つのタグノードで結ぶ。ローカル・拡大ローカル・全体グラフでタグを常時表示する。旧版で保存された表示オフ設定も常時表示になる。深さは初期値1で、2にするとタグ経由で別のノートに到達できる。

幅600px以上では本文下を左40％・右60％に分け、間隔を24pxとする。左は見出し・案内文、操作欄、事務所情報の順で、右にグラフを置く。600px未満では見出し・案内文、幅いっぱいのグラフ、操作欄、事務所情報の順に縦配置する。グラフは幅と高さがおおむね3対2で、最低高さ250px。ResizeObserverでコンテナ寸法の変化に追従する。

## 見出しと操作欄

見出しはh3の「グラフビュー」、案内文はpの「事例とタグのつながりを、動かして、たどって、楽しんでみてください。」とし、各16pxで表示する。見出しとpの間は8px、pから次の要素までは12px。スマホのグラフと操作欄、各画面の操作欄と事務所情報はそれぞれ24px空ける。

600px以上でタッチ操作に対応する環境は `any-pointer: coarse` で判定する。操作欄の右端をグラフ枠の18px手前まで広げる。元の列間24pxに対して操作欄を左列より6px広げる指定で実現する。600px未満は操作欄をグラフと同幅にする。タッチ環境と600px未満の画面では、余分な幅をスライダーに割り当て、高さと両アイコンの操作領域を32px以上とする。スライダーの背景を透明とし、3pxのトラックと20pxのつまみを描画してテーマ由来の黒い矩形を防ぐ。アイコンのボタン間は9px、通常のデスクトップは従来の6pxとする。ボタンには用途を示すアクセシブル名を付ける。

## 文字とノードの見やすさ

2026-11-19の調整では、深さ1・2の文字を画面上13px、深さ3と全体グラフを12pxとする。文字とノードにはグラフの表示倍率の逆数を掛け、ズーム時も画面上の寸法を保つ。ノード半径は接続数の平方根を使い、直径を8〜18pxに制限する。任意の `--dg-graph-label-size` は画面上の文字サイズを指定する値として扱い、旧24を1/3にする指定を削除する。

ノード数が1〜4でも初期位置を自動調整する。初期計算を120tick進め、表示倍率に応じて衝突判定の半径を補正して80tickずつ3回再計算する。周囲に35pxの余白を設けて中央に配置し、初期倍率の上限を2とする。全画面の目標エッジ長は80から40、反発力は−300から−80に変更する。通常の目標長40と反発力−100は維持する。エッジの線幅も画面上1pxに保つ。

ラベルはホバー・選択中、現在のノート、選択ノードの隣接先、現在のノートの直接接続先を優先し、残りは接続の多いノードから配置する。ノードの上下左右を候補とし、他の文字・ノードとの重なりを避ける。収まらないラベルは拡大・移動・ホバーや長押しで確認する。現在のノートとホバー・選択中の名前は優先して表示する。文字の白い輪郭で線上の視認性を確保する。

| `src/helpers/linkUtils.test.js` | タグの重複や非表示条件、一覧URL、既存のノート間リンクとバックリンクを検証する。 |
