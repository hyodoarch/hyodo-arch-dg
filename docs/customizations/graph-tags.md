# グラフビューのタグ表示

同じタグを持つ公開ノートを一つのタグノードで結ぶ。タグのないノートも、既存の内部リンクからグラフに表示される。タグ表示は初期オンで、ローカル・拡大ローカル・全体グラフのチェックボックスで切り替えられる。最後の状態をブラウザの `localStorage` に保存する。深さは初期値1で、2にするとタグ経由で別のノートに到達できる。

## 更新時に維持するファイル

| ルート相対パス | 変更内容と復元後の確認 |
| --- | --- |
| `src/helpers/linkUtils.js` | 既存のグラフ生成に `tagNodes` と `tagLinks` を追加する。公開かつグラフ表示対象のノートから、タグごとに1ノード、ノートとの組み合わせごとに1本の線を作る。通常のリンクとバックリンクの計算後に組み立て、Basesのデータから独立させる。 |
| `.eleventy.js`、`src/helpers/tagNotes.js`、`src/site/tags/tags.11tydata.js` | `tagSlug` を共用し、グラフと本文のタグリンクが既存の一覧ページへ向くことを確認する。対応する一覧がないタグはURLを空にする。空値、重複、内部タグの扱いは既存の `tagsForNote()` に従う。 |
| `src/site/_includes/components/graphScript.njk` | タグの状態に応じて探索前に接続線を取り込む。ローカルで起点と直接つながるタグはラベルを常時表示する。タグ一覧ではタグを起点にする。拡大グラフはブラウザ標準のダイアログで最前面に表示し、再描画や開閉時に古い描画待ちの処理を止める。マウスとタッチは描画中のノードの座標で当たり判定する。 |
| `.env` | `dgShowGraphDepthControl=true` で既存の深さ1〜3の操作欄を表示する。 |
| `src/site/styles/user/hyodo-footer.scss` | サイト固有のタグの配色と操作欄のスタイル。 |
| `src/helpers/linkUtils.test.js` | タグの重複や非表示条件、一覧URL、既存のノート間リンクとバックリンクを検証する。 |

DGテンプレートやEleventyの更新、設定・作業フォルダの再取得や置換で、データ生成、操作欄、深さ設定が失われることがある。独自SCSSとテストは通常の更新で残るが、全体置換や読込方法の変更では再統合が必要になる。ソースは通常cloneの該当差分から復元し、GitHub保存後は対応するコミットを参照する。`dist/graph.json` とCSSはNode.js 22の `npm run build` で再生成する。
